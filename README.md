# Hypothesis Testing Using Python

## 📌 Overview

This project contains different **Hypothesis Testing** techniques implemented using Python in **Google Colab**.

The main objective is to understand how statistical tests are used to compare means and proportions and interpret the results using p-values.

## 🛠️ Tools & Libraries

- Python
- Google Colab
- NumPy
- Pandas
- SciPy
- Statsmodels

## 📊 Tests Covered

### 1. One-Sample t-Test
Used to compare a sample mean with a known or hypothesized population mean.

### 2. Independent Two-Sample t-Test
Used to compare the means of two independent groups.

### 3. Paired t-Test
Used to compare two related or dependent samples, such as before-and-after measurements.

### 4. One-Proportion Z-Test
Used to test whether a sample proportion is significantly different from a hypothesized population proportion.

### 5. Two-Proportion Z-Test
Used to compare the proportions of two independent groups.

## 📈 Decision Rule

Significance Level:

**α = 0.05**

- **p-value < 0.05** → Reject H₀
- **p-value ≥ 0.05** → Fail to reject H₀
